# NovelAI 绘图增强版 · AstrBot

修改版作者 **Yasumi**。将现有 NekroAgent 增强版移植到 AstrBot，保留原项目 [luoxiQAQ/nekro-plugin-novelai](https://github.com/luoxiQAQ/nekro-plugin-novelai) 的 MIT 许可证、版权声明和预设来源说明。随包预设来自原作者 luoxiQAQ，不作为 Yasumi 原创署名。

适用环境：**AstrBot 4.28.2 或更高版本，Python 3.12+，NapCat / OneBot V11**。已对本机 4.28.2 接口进行隔离集成验证；其他版本、其他消息平台尚未验证。插件不依赖 NekroAgent 运行，也不修改 AstrBot 核心代码。

## 安装

仓库：[youthen-chang/astrbot_plugin_novelai_enhanced](https://github.com/youthen-chang/astrbot_plugin_novelai_enhanced)。可在 AstrBot 的仓库安装入口粘贴此地址，或在 [Releases](https://github.com/youthen-chang/astrbot_plugin_novelai_enhanced/releases) 下载插件 ZIP 后从文件安装。

1. 在 AstrBot 的插件管理中，选择从文件安装，上传 `astrbot_plugin_novelai_enhanced-1.0.0.zip`。如果部署没有文件安装入口，解压到 AstrBot 的 `data/plugins/astrbot_plugin_novelai_enhanced/`，确保该目录内直接有 `main.py` 与 `metadata.yaml`，再按部署提供的方式重载插件。
2. 安装依赖：通常由框架读取 `requirements.txt` 自动安装；若提示依赖缺失，在 **AstrBot 自己使用的 Python 环境**中安装该文件。
3. 在插件配置中填写 **NovelAI API Token**，按需设置代理、翻译模型、画廊地址和密钥。
4. 如需聊天管理指令，在 `插件管理员` 中填写平台用户 QQ 号。它与 AstrBot 管理员分开，初始为空。

作者署名为 Yasumi；安装包不含真实 Token、代理凭据、运行配置、图片、聊天记录、用户或群名单。

## 绘图

```text
/画图 人物预设名，风格040，花田，横
/画图 1girl, white dress -n:glasses, hat。
/重画 微笑
/重画 -N：hat.
/重画 -n:。
/额度
/绘图帮助
```

在 `画图触发词`、`重画触发词` 中可分别设置带 `/` 或不带 `/` 的文字，如 `西西来点` 与 `西西重画`。保存后生效，不需要 @ 机器人。无斜杠触发词必须在消息开头，可直接接描述，也可用空格或 `+` 分隔。带斜杠时在指令后加空格。

仅画图和重画受自定义触发词影响，其余指令继续带 `/` 使用。`保留原画图和重画指令` 开关默认关闭，关闭后只使用配置中的两个触发词。启用可额外使用 `/画图`、`/nai`、`/nai画图`、`/novelai`、`/重画`、`/redraw`。

支持 `@人物`、`#风格`、`人物=名称`、`风格=名称` 以及已知预设裸名。`竖/方/横` 分别对应 832×1216、1024×1024、1216×832。

单次负面词使用 **`-n:内容。`**，n 不区分大小写、冒号兼容中英文、句号兼容 `.` 与 `。`，小数权重不被误截断。追加到全局负面词，不覆盖后台配置。重画继承上一张的额外负面词；提供新 `-n:` 则替换，空内容可清除。无结束句号的请求在提交前拒绝，不扣额度。

将图片与画图指令同发，或回复图片再发画图指令，即为图生图。`/来点 人物预设名`、`/来点nai`、`/laidian` 继续支持换人物；无引用时仅查找当前会话最近收到的图片，不跨会话取图。

`/看参数`、`/反推`、`/查看参数`、`/naimeta` 可查看引用图片、同发图片或会话上一张生成图片的 PNG 参数。聊天发送的图片去掉元数据，原图和参数保存在插件数据目录及配置好的画廊。

## 自然语言工具

提供 `novelai_generate` 和 `novelai_img2img` 两个 AstrBot LLM 工具；需要你为聊天模型启用工具调用，并按框架的唤醒规则与机器人对话。

工具与手动指令共用同一条队列、名单、消息去重及额度检查。发送图片的工具先返回受理结果，再由插件完成通知，避免长时间排队被框架的工具超时取消。同一平台消息只能创建一个生图任务，模型重复调用不重复扣额。

成功时完成文字和图片合在同一条消息发送，不添加 `≡NA≡:` 前缀。

## 额度、白名单、队列

**初装时每日限额、群白名单、私聊白名单均关闭。** 默认展示的数值为共享总额度 100、每群 20、每私聊 5；开关关闭时不拦截现有使用。

启用后，所有群聊和私聊共用每日总额度；同时每个会话有独立限额，可在后台分别填写：

```text
987654321=1
123456789=20
```

群聊默认额度针对每个群，私聊默认额度针对每个私聊用户。白名单群内所有成员共享群额度，不额外设置每人每日限制。`0` 表示普通用户不可画，`-1` 表示不限。也支持完整会话键，如 `napcat:机器人QQ:group_群号=20`，可区分同一部署的不同机器人实例。

北京时间每日 00:00 刷新。任务入队时原子预占额度，图片成功保存后扣一次。失败或结果不确定不扣插件额度；这不代表 NovelAI 返还实际 Anlas。群聊和私聊使用不同会话键，避免相同数字 ID 混淆。额度保存在 SQLite，重载或异常退出不会自动重新生图。

**插件管理员完全免除每日额度，也不占用总额度**，但仍受白名单、黑名单及队列约束。QQ群管理员或 AstrBot 管理员不会自动成为插件管理员。额度分配仅在后台修改，聊天中只提供 `/额度` 查询。

群、私聊白名单独立开关，每行一个群号或用户号；可附备注。开启但名单为空即全部禁止。黑名单仍优先生效。

所有画图、重画、换人物、LLM 文生图和图生图统一 FIFO，一次一个生成请求。每位用户同时最多一个未完成任务，默认全局最多 20 个未完成任务。前台仅回复可编辑的“正在绘制中”文本，不展示队列位置。

429 在后台等待后重试，默认至少 15 秒，最多重试 3 次；遵循服务端更长的 Retry-After，单次最多 600 秒。重试不换种子、参数或 Token；401/402 才有限轮换多个 Token。网络中断属于结果不确定，不自动重新生成。发送图片或上传画廊失败不会重新绘图、重复扣额度。

## 预设

安装包**直接包含** `presets.json`：1062 个人物、61 个风格，来源见 [PRESET_SOURCE.md](PRESET_SOURCE.md)。第一次加载自动初始化到 `data/plugin_data/astrbot_plugin_novelai_enhanced/presets.json`；更新不覆盖已有文件，也不会补回手动删除的预设。

插件详情的 **Pages → presets** 提供搜索、编辑、删除、合并导入和导出。页面使用 AstrBot 自带的登录和页面 bridge，不额外提供公网管理入口。

聊天指令 `/人物列表 [页码]`、`/风格列表 [页码]` 每页 50 项。插件管理员可使用 `/添加人物 名称 提示词`、`/删除人物 名称`、`/添加风格 名称 提示词`、`/删除风格 名称`，以及 `/拉黑 [QQ或群号] [备注]`、`/解除拉黑 [QQ或群号]`、`/黑名单`。

原版兼容命令 `/生成画图密钥 [次数]`（别名 `/生成密钥`）、`/增加画图次数 密钥 次数`、`/画图密钥列表`、`/删除画图密钥 密钥` 仍管理本插件数据目录的 `gallery_draw_keys.json`。它只用于兼容原画廊的共享文件机制，**不是画廊上传密钥，也不会自动赋予任意网站画图权限**。

## 代理与云端迁移

- `API_PROXY`：可信 NovelAI 反代的基础地址，不带 `/ai/generate-image`，插件自动追加 `/ai/` 和接口路径。
- `HTTP_PROXY`：当前 AstrBot 环境能访问的 HTTP/SOCKS5 代理地址；留空不使用环境变量代理。
- 云端可直接访问 `https://image.novelai.net` 时两项均可留空。Docker 中的 `127.0.0.1` 指向容器自己，不能直接连接另一台电脑的本地代理。
- `翻译大模型` 选择 AstrBot 已配置的聊天提供商，留空则不翻译。翻译模型名单、API 及密钥由 AstrBot 管理，不复制 NekroAgent 模型组。

云端上传同一个 ZIP 即可，预设已随包提供；仍须重新填写 Token、代理、名单、额度、翻译提供商和画廊上传凭据。不同部署各自排队、计算额度；同一 NovelAI Token 若同时在两个部署绘图，仍可能触发服务端 429。

画廊上传填写 `/api/upload` 地址及专用上传密钥，接口兼容现有画廊；上传任务持久化，失败后台重试。元数据含 AstrBot 来源标识，但画廊卡片显示的来源名称由网站为该上传密钥分配的来源决定。若复用旧 NekroAgent 上传密钥，网站可能仍显示旧来源名，需要在画廊管理中另建 AstrBot 来源。

需要迁移自定义预设时，在旧插件导出 JSON，再在本插件 Pages 中导入。不要复制旧框架的配置文件、Token 数据、SQLite 数据库或整个插件运行目录。AstrBot 的数据目录需持久挂载。

## 开发验证

```text
python -m pip install -r requirements.txt pytest ruff
python -m pytest -q
python -m ruff check .
python -m ruff format --check .
```

默认测试纯逻辑；额外设置 `ASTRBOT_SOURCE_DIR` 为一份 AstrBot 源码路径可运行真实框架的集成测试。测试使用临时数据目录、模拟 NovelAI 响应及 NapCat 发送器，不调用真实付费生成，不发送聊天消息。端到端实际出图需安装并配置后另行验收。
